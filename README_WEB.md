# Pulsar Web v1.1.1

Отдельная веб-сборка на базе **Pulsar v10.9.2**. Локальная версия не изменена.

## Что изменено

- Локальный `http.server` заменён на Flask + Gunicorn.
- Сервер слушает `0.0.0.0` и порт `PORT`, предоставленный хостингом.
- У каждого браузера своя случайная `HttpOnly`-сессия.
- Клиент Яндекс Музыки, авторизация, задания загрузки и аудиокэш изолированы по сессиям.
- Аудио выдаётся только в рамках той же сессии, а не из общего публичного каталога.
- Временные сессии и аудиокэш очищаются после 12 часов неактивности.
- Добавлены `requirements.txt`, `render.yaml` и health-check `/health`.

Интерфейс, стили, визуализаторы, движок и пресеты взяты из v10.9.2 без намеренного редизайна.

## Развёртывание

1. Создай новый GitHub-репозиторий `pulsar-web`.
2. Загрузи в корень репозитория всё содержимое этой папки (не архив и не внешнюю папку-обёртку).
3. На Render подключи GitHub и создай новый сервис через **New → Blueprint**.
4. Выбери репозиторий. Render прочитает `render.yaml`, установит зависимости и запустит сайт.
5. После успешного деплоя открой выданный Render адрес `https://....onrender.com`.

Нужны аккаунты GitHub и Render. Покупать домен, регистрировать Yandex OAuth-приложение или передавать пароли не требуется.

## Ограничения первой версии

- Для бесплатного сервиса задан один Gunicorn worker: сессии пока хранятся в памяти процесса.
- После перезапуска/сна инстанса сессии и авторизация сбрасываются; пользователь входит в Яндекс заново.
- Файловый кэш временный и не является постоянным хранилищем.
- Очередь и плейлисты существуют в памяти вкладки и сбрасываются при перезагрузке, как и в исходной версии.
- Бесплатный Render может усыплять неактивный сервис; первое открытие после простоя может занять около минуты.
- Совместимость сторонней библиотеки `yandex-music` с текущим сервисом Яндекса нужно проверять на реальном развёрнутом сайте.

## Локальный запуск в Windows (HTTPS для VK ID)

1. Установи Python 3.11+.
2. Установи `mkcert` (например, командой `winget install FiloSottile.mkcert`).
3. Скачай ZIP ветки `web-v1.2.0` и распакуй его.
4. Нажми правой кнопкой на `run_local.bat` → «Запуск от имени администратора». Это необходимо для порта 443.
5. При первом запуске BAT создаст виртуальное окружение, установит зависимости и локальный доверенный сертификат.
6. Открой **https://localhost**.

В настройках VK ID должен быть добавлен доверенный Redirect URL `https://localhost/`. Сертификаты `localhost+2.pem` и `localhost+2-key.pem` создаются локально и не должны публиковаться или отправляться в GitHub. Если порт 443 занят, останови программу, которая его использует, и повтори запуск.

Запросы VK Audio API будут выполняться локальным сервером на том же компьютере, что и браузер. Не публикуй локальный сервер в интернет и никому не передавай access token.

### Исследование официального веб-клиента VK Музыки

- В локальной версии открой настройки VK Музыки, нажми «Открыть окно VK» и авторизуйся в отдельном Chromium/Chrome.
- Затем нажми «Исследовать VK Музыку». Pulsar откроет `https://vk.ru/audio`, соберёт метаданные сетевых запросов и структуру JSON-ответов.
- Диагностика фиксирует только HTTP-метод, хост, путь, имена query/form-полей, HTTP-статус, тип ответа, имена верхнеуровневых JSON-полей и размеры массивов.
- Значения query/form-параметров, тела запросов, cookies, заголовки авторизации, токены и ссылки на аудиопотоки не сохраняются и не выводятся.
- Результаты доступны в консоли браузера (F12 → Console) под группой `[Pulsar VK Music web inspection]`.
- Проверка доступна только локально при `PULSE_LOCAL_VK_BROWSER=1`; на публичном хостинге endpoint отвечает HTTP 403.

### Автоматическая авторизация VK Music (эксперимент)

- В локальной версии кнопка «Открыть окно VK» запускает отдельный Chromium через Playwright с постоянным профилем `PULSE_DATA_DIR/vk-browser-profile`.
- Войди в VK в этом окне, затем нажми «Проверить сессию VK». Сервер сам читает cookies из профиля и запрашивает веб-токен с локального компьютера.
- Cookies и профиль остаются на этом компьютере; токен не возвращается в интерфейс и не сохраняется этим тестовым endpoint.
- При первом запуске `run_local.bat` установит Playwright и Chromium. Окно браузера можно закрывать после проверки; профиль сохраняется между запусками.
- Это эксперимент: VK может изменить схему выдачи веб-токена. Для локального браузера требуется установленный Google Chrome либо Chromium, загружаемый Playwright.
