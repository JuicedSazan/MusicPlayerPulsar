# Pulsar VK Bridge

Небольшое расширение для Chromium (Manifest V3), которое позволяет веб-плееру Pulsar подключить VK Music, используя вашу текущую сессию VK в браузере.

Страница плеера запрашивает у расширения cookies `remixsid` и `p` для `vk.ru` (а также запасной вариант для `vk.com`) и user agent. Полученные данные страница сама отправляет на свой backend по HTTPS. Расширение само никуда cookies не передаёт, не сохраняет их и не пишет их в консоль.

Расширение работает только в браузерах на Chromium: Chrome, Edge, Yandex Browser, Opera, Vivaldi и т. п.

## Установка

1. Откройте страницу управления расширениями:
   - Chrome/Edge/Yandex Browser: `chrome://extensions` (в Edge также `edge://extensions`).
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `vk_bridge` (в ней находится `manifest.json`).
5. Откройте плеер и подключите VK Music. Если вы уже авторизованы в VK в этом браузере, сессия подхватится автоматически.

После установки расширение можно отключить или удалить на той же странице `chrome://extensions`.

## Какие данные используются

- Только cookies доменов `vk.ru`, `login.vk.ru`, `vk.com`, `login.vk.com` (`remixsid`, `p`) и user agent браузера.
- Данные передаются исключительно странице плеера (`pulse-vinyl-web-v11-test.onrender.com`, `pulse-vinyl-web.onrender.com`, `localhost`) по HTTPS.
- Расширение ничего не сохраняет и не отправляет данные на сторонние серверы.

## Удаление

Откройте `chrome://extensions`, найдите «Pulsar VK Bridge» и нажмите **«Удалить»**. Никаких следов в браузере расширение не оставляет.
