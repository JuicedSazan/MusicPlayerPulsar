## Бесплатные хостинги для VK-входа (вариант 1)

Серверному окну входа VK нужен headless Chromium: страница `vk.ru` живёт в DOM+JS,
а после подтверждения кода VK подгружает тяжёлые ресурсы. На Render Free доступно
**512 МБ RAM и 0.1 CPU**, этого не хватает — инстанс падает по памяти (`exceeded
memory limit`). Ветка `test/vk-remote-browser-login` в Render-сервисе остаётся
рабочей для всего, кроме шага с числовым кодом; `main` не тронут.

Кандидаты (проверено по открытым источникам на ноябрь 2026).

**Важно про Hugging Face:** Space с исполняемым кодом (Gradio или Docker) теперь
требует платной подписки PRO — бесплатны только **Static** Spaces, а они не умеют
запускать Python-сервер. Для этого проекта HF не подходит.

| Хостинг | RAM | Деньги | Минусы |
|---|---|---|---|
| ~~Hugging Face Spaces (Docker/Gradio)~~ | 16 ГБ RAM, 2 vCPU | **нужна PRO-подписка** | на бесплатном плане исполняемый код запрещён; Static не запускает Python |
| **[Oracle Cloud Always Free](https://www.oracle.com/cloud/free/)** (VM.Standard.A1, ARM) | до **24 ГБ RAM / 200 ГБ диска** | 0 | нужна карта для верификации; бывает `Out of host capacity`; Oracle может забрать «простаивающий» инстанс, поэтому нужен keep-alive |
| **[Google Cloud Free Tier](https://cloud.google.com/free)** (`e2-micro`, x86) | 1 ГБ RAM, 30 ГБ диска | 0 (карта для верификации) | маленький процессор, но Chromium тянет |
| **[Serv00](https://www.serv00.com/)** | shared, Python/Node, SSH | 0, без карты | доля CPU, правила против «тяжёлых» процессов |
| **[Koyeb](https://www.koyeb.com/)** | 512 МБ | 0, без карты | тот же дефицит памяти, что у Render |

**Рекомендация (обновлено):** Google Cloud Run (постоянный бесплатный ресурс, 1 ГБ на инстанс)
и с огромным запасом памяти. Порядок действий:

1. Создайте Space: `Docker` → Blank, публичный или приватный.
2. В репозитории Space положите файлы этой ветки (включая `Dockerfile`).
3. Space соберётся, приложение откроется на `https://<user>-<space>.hf.space`.
4. В настройках Space включите постоянное хранилище (`persistent storage`), если
   нужны сессии между перезапусками.
5. Для бесплатного «не засыпать» добавьте внешний пингер раз в 24 часа или
   оставьте как есть — просыпание занимает ~30 секунд, QR-экран это переживёт.

**Критично для Chromium в контейнере:** `--no-sandbox` уже включён в
`vk_remote_browser.py`, а Dockerfile ставит системные библиотеки и
`playwright install chromium` (`PLAYWRIGHT_BROWSERS_PATH=/ms-playwright`).

Проверка после переноса: откройте `/health` → `200`, затем в плеере
«Настроить VK Музыку» → «ВОЙТИ ЧЕРЕЗ VK» → QR → скан приложением ВК → сервер
принимает код → «VK Музыка подключена» → поиск **VK** → трек играет.
